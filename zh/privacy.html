2. 本网站的数据收集

本网站为静态托管。我们不会直接收集或存储访客的任何个人数据。

本网站不使用任何需要征得同意的追踪 Cookie、分析服务（如 Google Analytics）或广告网络。因此，根据相关数据保护法规（TDDDG / GDPR），无需设置 Cookie 授权弹窗。

3. 网站托管

本网站作为静态网页通过 GitHub Pages 服务进行托管：

  • GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA)。向美国的数据传输均基于欧盟委员会的标准合同条款 (SCC) 以及《欧盟-美国数据隐私框架》。访问时的服务器日志信息（如 IP 地址、访问时间戳）仅用于防御网络攻击及确保系统安全稳定运行（GDPR 第 6 条第 1 款 (f) 项）。

4. 配方本地存储（非云端）

您创建的所有披萨配方、笔记、烘烤记录与面团设置均仅保存在您的本地设备上（SharedPreferences / 本地存储空间）。这些配方数据绝不会上传或传输至任何云端服务器。

5. 应用基础设施 (Firebase)

Android 应用程序使用 Google Firebase 实现核心功能：

  • Firebase Authentication（登录与账户管理）
  • Cloud Firestore（仅用于同步账户及 Pro 专业版授权状态；配方数据不存储于云端）
  • Crashlytics（匿名崩溃报告，用于持续改进应用体验）

6. 您的权利

您有权随时免费查询所存储的个人数据及其来源、接收方和收集目的。您亦有权要求更正或删除这些数据。

您亦有权向主管的数据保护监管机构提出申诉（GDPR 第 77 条）。

7. 账户与数据删除

如果您希望删除账户及所有相关数据，请发送邮件主题为 "Account Deletion" 的电子邮件至 pizzatastico@gmail.com. 收到您的请求后，您的账户及所有存储的数据将在 30 天内从我们的系统中永久删除。
