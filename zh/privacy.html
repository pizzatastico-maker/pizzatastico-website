2. 本网站的数据收集

本网站以静态方式提供。所有网页字体与应用商店徽标均托管于本地服务器，不会向 Google Fonts 发起外部请求。

未经您的明确同意，我们不会设置任何跟踪 Cookie，也不会加载外部统计脚本。您可随时通过页脚的“Cookie 设置”撤回或更改选择。

2b. 无 Cookie 匿名统计与可选 Google Analytics 4

1) 无 Cookie 匿名统计（GDPR 第 6(1)(f) 条）：页面加载时仅通过 Cloud Firestore 记录纯技术性匿名指标（受访页面、语言、设备类型、来源分类及应用商店点击），不使用 Cookie 且不存储 IP 地址。 2) Google Analytics 4（GDPR 第 6(1)(a) 条）：仅在您点击“允许统计”后加载 Google Analytics 4（Google Ireland Limited），并启用 IP 匿名化及禁用广告画像（ad_storage=denied）。

3. 网站托管

本网站作为静态网页通过 GitHub Pages 服务进行托管：

  • GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA)。向美国的数据传输均基于欧盟委员会的标准合同条款 (SCC) 以及《欧盟-美国数据隐私框架》。访问时的服务器日志信息（如 IP 地址、访问时间戳）仅用于防御网络攻击及确保系统安全稳定运行（GDPR 第 6 条第 1 款 (f) 项）。

4. 配方本地存储（非云端）

您创建的所有披萨配方、笔记、烘烤记录与面团设置均仅保存在您的本地设备上（SharedPreferences / 本地存储空间）。这些配方数据绝不会上传或传输至任何云端服务器。

5. 应用基础设施 (Firebase)

Android 应用程序使用 Google Firebase 实现核心功能：

  • Firebase Authentication（登录与账户管理）
  • Cloud Firestore（用于同步 Pro 许可证状态，以及仅在您自愿绑定账号后提供配方与设置的私人云端备份）
  • Crashlytics（匿名崩溃报告，用于持续改进应用体验）

6. 广告（Google AdMob）

在应用的免费基础版中，广告通过 Google AdMob（Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Ireland）提供。在 iOS 上，本应用严格以无跟踪（No-Tracking）模式运行，不访问 IDFA 且不弹出 App Tracking Transparency（ATT）授权提示——仅请求非个性化广告，不进行任何跨应用跟踪。在 Android 上，仅当您在欧洲经济区、英国或适用地区通过 Google User Messaging Platform（UMP）明确同意后，才会使用广告 ID 和个性化广告（否则仅展示非个性化广告）。购买 Pizzatastico Pro 即可永久移除广告。

7. 匿名烘焙遥测与社区披萨指数

为提供面团汇总基准与全球社区烘焙趋势（如平均含水率、含 Tipo 00/0/1 混合面粉的面粉蛋白质含量、发酵阶段、烤炉温度、面团风味平衡评分及披萨风格），应用在规划和完成烘焙会话时仅记录严格匿名的技术指标。数据仅关联随机生成的会话 ID（RFC-4122 v4 UUID），不含任何个人身份信息，并通过 HTTPS 加密发送至 Cloud Firestore。参与完全自愿，您可随时在应用设置中关闭。

您亦有权向主管的数据保护监管机构提出申诉（GDPR 第 77 条）。

9. 账户与数据删除

如果您希望删除账户及所有相关数据，请发送邮件主题为 "Account Deletion" 的电子邮件至 pizzatastico@gmail.com. 收到您的请求后，您的账户及所有存储的数据将在 30 天内从我们的系统中永久删除。
