2. Shromažďování údajů

Tento web je hostován staticky. Přímo neshromažďujeme ani neukládáme žádné osobní údaje návštěvníků.

Tento web nepoužívá žádné soubory cookie vyžadující souhlas, analytické služby (jako je Google Analytics) ani reklamní sítě. Lišta pro souhlas se soubory cookie proto není podle předpisů o ochraně osobních údajů (TDDDG / GDPR) vyžadována.

3. Webhosting

Tento web je hostován jako statická stránka prostřednictvím služby GitHub Pages:

  • GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). Předávání údajů do USA se řídí standardními smluvními doložkami EU (SCC) a rámcem pro ochranu osobních údajů mezi EU a USA (EU-U.S. Data Privacy Framework). Standardní protokoly serveru (např. IP adresa, čas přístupu) jsou zpracovávány výhradně pro zajištění bezpečnosti a integrity systému (čl. 6 odst. 1 písm. f) GDPR).

4. Místní ukládání receptů (bez cloudu)

Veškeré vámi vytvořené recepty na pizzu, poznámky, záznamy o pečení a nastavení těsta jsou uloženy výhradně lokálně v paměti vašeho zařízení (SharedPreferences / lokální paměť zařízení). Tato data receptů se nikdy neodesílají ani nepřenášejí na cloudové servery.

5. Infrastruktura aplikace (Firebase)

Aplikace pro Android využívá Google Firebase pro základní funkce:

  • Firebase Authentication (přihlášení a správa účtu)
  • Cloud Firestore (výhradně pro stav účtu a licence Pro; v cloudu se neukládají žádné recepty)
  • Crashlytics (anonymní hlášení chyb za účelem vylepšování aplikace)

6. Vaše práva

Máte právo bezplatně požadovat informace o svých uložených osobních údajích, jejich původu, příjemcích a účelu jejich zpracování. Máte také právo požadovat jejich opravu nebo výmaz.

Máte také právo podat stížnost u příslušného dozorového úřadu pro ochranu osobních údajů (čl. 77 GDPR).

7. Smazání účtu a údajů

Pokud si přejete smazat svůj účet a veškeré související údaje, zašlete prosím e-mail s předmětem "Account Deletion" na adresu pizzatastico@gmail.com. Po obdržení vaší žádosti bude váš účet a veškerá uložená data trvale odstraněna z našich systémů do 30 dnů.
