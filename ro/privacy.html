2. Colectarea datelor

Acest site web este găzduit static. Nu colectăm și nu stocăm direct date cu caracter personal de la vizitatori.

Acest site web nu utilizează module cookie care necesită consimțământ, servicii de analiză (cum ar fi Google Analytics) sau rețele de publicitate. Prin urmare, un banner de consimțământ pentru cookie-uri nu este necesar conform reglementărilor privind protecția datelor (TDDDG / GDPR).

3. Găzduire web

Acest site web este găzduit ca un site static prin intermediul serviciului GitHub Pages:

  • GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, SUA). Transferul de date către SUA este reglementat de Clauzele Contractuale Standard ale UE (SCC) și de Cadrul de confidențialitate a datelor UE-SUA. Jurnalele standard ale serverului (de ex. adresa IP, marcajul temporal al accesului) sunt prelucrate exclusiv pentru securitatea și integritatea sistemului (art. 6 alin. 1 lit. f GDPR).

4. Stocarea locală a rețetelor (fără cloud)

Toate rețetele de pizza, notițele, sesiunile de coacere și setările aluatului create de tine sunt stocate exclusiv local pe dispozitivul tău (SharedPreferences / memoria locală a dispozitivului). Aceste date despre rețete nu sunt niciodată încărcate sau transmise către servere cloud.

5. Infrastructura aplicației (Firebase)

Aplicația Android utilizează Google Firebase pentru funcționalitățile de bază:

  • Firebase Authentication (autentificare și gestionarea contului)
  • Cloud Firestore (exclusiv pentru cont și statutul licenței Pro; nicio rețetă nu este stocată în cloud)
  • Crashlytics (rapoarte anonime de eroare pentru îmbunătățirea aplicației)

6. Drepturile dumneavoastră

Aveți dreptul de a solicita gratuit informații despre datele dumneavoastră stocate, originea acestora, destinatarii și scopul colectării. De asemenea, aveți dreptul de a solicita rectificarea sau ștergerea acestora.

De asemenea, aveți dreptul de a depune o plângere la o autoritate de supraveghere competentă pentru protecția datelor (art. 77 GDPR).

7. Ștergerea contului și a datelor

Dacă doriți să vă ștergeți contul și toate datele asociate, vă rugăm să trimiteți un e-mail cu subiectul „Account Deletion” la pizzatastico@gmail.com. După primirea solicitării dumneavoastră, contul și toate datele stocate vor fi șterse definitiv din sistemele noastre în termen de 30 de zile.
