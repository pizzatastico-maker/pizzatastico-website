2. Raccolta Dati

Questo sito web è ospitato staticamente. Non raccogliamo né memorizziamo direttamente i dati personali dei visitatori.

Questo sito web non utilizza cookie di tracciamento soggetti a consenso, strumenti di analisi o reti pubblicitarie. Pertanto non è richiesto alcun banner per i cookie ai sensi del GDPR.

3. Web Hosting

Questo sito web è ospitato come presenza statica tramite il servizio GitHub Pages:

  • GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). Il trasferimento dei dati negli USA si basa sulle Clausole Contrattuali Standard della Commissione UE e sull'EU-U.S. Data Privacy Framework. I log del server (es. indirizzo IP) vengono elaborati solo per motivi di sicurezza del sistema (Art. 6 par. 1 lett. f GDPR).

4. Salvataggio Locale delle Ricette (Nessun Cloud)

Tutte le ricette, note, sessioni di cottura e impostazioni create vengono salvate esclusivamente nella memoria locale del tuo dispositivo (Shared Preferences). Nessun dato sulle ricette viene mai caricato sul cloud.

5. Infrastruttura App (Firebase)

L'applicazione Android utilizza Google Firebase per le funzionalità principali:

  • Firebase Authentication (Login e gestione account)
  • Cloud Firestore (Esclusivamente per account e stato licenza Pro; nessuna ricetta viene salvata nel cloud)
  • Crashlytics (Segnalazione anonima dei bug per migliorare l'app)

6. I tuoi diritti

Hai il diritto di richiedere gratuitamente informazioni sui tuoi dati memorizzati, sulla loro origine, sui destinatari e sullo scopo della raccolta. Hai anche il diritto di richiederne la correzione o la cancellazione.

Hai inoltre il diritto di proporre reclamo a un'autorità di controllo competente per la protezione dei dati (Art. 77 GDPR).

7. Cancellazione dell'Account e dei Dati

Se desideri cancellare il tuo account e tutti i dati associati, invia un'e-mail con oggetto "Cancellazione Account" a pizzatastico@gmail.com. Una volta ricevuta la richiesta, il tuo account e tutti i dati memorizzati verranno rimossi permanentemente entro 30 giorni.
